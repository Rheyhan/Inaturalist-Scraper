# Inaturalist Scraper

A Streamlit app to scrape and download images from the INaturalist platform based on user-defined criteria.

LIVE APP: [CLICK HERE](https://inaturalist-downloader.streamlit.app/)

This was built as a personal project to gather datasets for computer vision purposes. But i guess, imma share it with y'all since it'd be useful for some people.

## Usage
1. Either use the live app link above or
2. use the code locally by using [DEBUG.IPYNB](DEBUG.IPYNB) and installing the required packages from [requirements.txt](requirements.txt).

## Features
- Search for images by common name, scientific name, or taxon ID.
- Specify the number of images to download.
- Download images in a ZIP file.

## Disclaimer
This tool is intended for educational and research purposes only. Please ensure that you comply with INaturalist's terms of service and respect copyright and usage rights of the images you download.
